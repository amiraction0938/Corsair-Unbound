# Changelog

All notable changes to Corsair Unbound are documented here.

## 1.1.0 — Product surface consolidation

- Restored the full Dashboard product surface at the repository root.
- Added settings, profiles, activity, network observation, intelligence, evidence, agent context, backup/restore, and replay/regression UI.
- Expanded background message handlers for the dashboard and regression flows.
- Unified v8 product behavior with the hardened current runtime.
- Added bounded telemetry import/restore with rollback support.
- Strengthened migration/export coverage for profiles, settings, regression cases, events, evidence, graph data, chains, and DNR metadata.
- Hardened behavior intelligence scoring, confidence, verdicts, reasons, and metrics.
- Added popup access to Dashboard, theme controls, and Safe Redirect Resolver controls.
- Added repository-level validation workflow and focused runtime self-test.

## 1.0.x — Runtime hardening

- Hardened DNR registry management and reconciliation.
- Added transaction locking and rollback paths.
- Added hostname normalization, observation, evidence, redirect-chain handling, bounded storage, and migration support.
