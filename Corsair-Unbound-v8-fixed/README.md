# Historical v8 source

This directory preserves the earlier Corsair Unbound product surface for historical reference and regression comparison.

## Important

- The **repository root** is the source of truth for the current 1.1.0 product.
- This directory is **not** the active runtime entry point.
- The current root runtime reuses the useful product concepts from this historical implementation while using the hardened current backend.

The historical files are intentionally kept here so future maintenance can trace where older UI and behavior contracts originated.
